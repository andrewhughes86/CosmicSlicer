# CosmicSlicer — instructions for agents

CosmicSlicer is a slicer for FFF 3D printers: a Rust rebuild of OrcaSlicer (egui + wgpu), in
the Cosmic family's look (CosmicDMS, CosmicCut). OrcaSlicer is AGPL-3.0; CosmicSlicer uses its
option definitions, settings layout and icons, so CosmicSlicer is AGPL-3.0-or-later too.

## The first rule: never crash
OrcaSlicer's crashes are the reason this exists.
- No `unwrap`, `expect`, `panic!`, `unreachable!`, `todo!` or `unsafe` in non-test code (the
  workspace lints deny them). Input-derived numbers are hostile: `get()` not `[i]`, finite
  checks, caps on sizes and counts (see `model::stl`, `state::Session::bed`).
- egui asserts on some layout misuse (e.g. `add_space` inside a `Grid`). Every page, dialog,
  settings page and canvas tool is drawn headlessly by `app::smoke` tests; add new UI there.
- `CosmicSlicerApp::ui` catches a panic in a frame, closes dialogs and keeps the project.
  That is a last resort, not an error path: fix the bug.

## Layout
- `crates/config` — OrcaSlicer's option definitions and Tab layout
  (`assets/settings/orca_settings.json`, generated by `tools/extract_orca_settings.py` from
  OrcaSlicer's `PrintConfig.cpp` and `Tab.cpp`), values, presets. Values are stored as
  OrcaSlicer serialises them (vectors comma-separated, bools `1`/`0`).
- `crates/model` — meshes, objects, plates, STL/OBJ readers, primitives, arrange.
- `crates/engine` — the slicer: `slicing` (mesh → layer shapes), `walls`, `plan` (top /
  bottom / solid / sparse regions per island), `infill`, `skirt`, `support`, `gcode` (order,
  travel, cooling, G-code, estimates, Preview moves). `geom` wraps i_overlay under
  `catch_unwind`; `settings` clamps every value it reads. `slice()` never panics.
  `SLICE_FILE=x.stl cargo test --release -p CosmicSlicer-engine slice_a_file -- --nocapture`
  times a real model.
- `crates/ui-egui` — the UI. `slicer.rs` runs the engine on a thread (results checked against a
  settings fingerprint and the model revision); `preview.rs` colours toolpaths. `state.rs` is the session (all edits go through its methods, which
  checkpoint undo); `topbar`, `sidebar`, `settings`, `pages`, `dialogs`, `menus`; `viewport/`
  is the 3D canvas (wgpu renderer, camera, gizmos, overlays).
- `apps/CosmicSlicer` — the binary and its command-line automation.

## Conventions
- Colours only from `theme::Tokens` (the Cosmic palettes); containers from `ui_kit`.
- Icons are OrcaSlicer's SVGs in `assets/icons/orca/`, recoloured into the theme by
  `icons::colourise` (teal → accent, greys → ink); CosmicSlicer's own art goes in
  `assets/icons/cosmic/` and wins over a same-named Orca icon.
- Units inside are millimetres and degrees, as in OrcaSlicer.
- Regenerate the settings JSON with
  `python3 tools/extract_orca_settings.py <OrcaSlicer>/src assets/settings/orca_settings.json`.

## Before finishing
`cargo fmt --all`, `cargo clippy --workspace --all-targets` (no warnings),
`cargo test --workspace`. Check UI changes with screenshot runs, which save nothing:
`cargo run -- --add Cube --tab preview --screenshot out.png` (see `--help`).
